1. Introduction
Cette Politique de Confidentialité explique comment les données sont collectées, utilisées et protégées lors de l'utilisation de l'ensemble des robots et services (ci-après "les Services") fournis par le développeur (ci-après "nous"). Nous nous engageons à protéger votre vie privée et à traiter vos données de manière transparente.

2. Données Collectées
Nous collectons uniquement les données strictement nécessaires au fonctionnement technique des Services. Ces données se divisent en deux catégories :

A. Données Automatiques (Métadonnées) Lors de l'interaction avec les Services, nous recevons automatiquement de Discord certaines informations standard, notamment :

Identifiants (IDs) : Votre ID utilisateur Discord, l'ID du serveur (Guild) où l'interaction a lieu, et l'ID du canal textuel.

Permissions : Les permissions de votre rôle pour vérifier si vous avez le droit d'exécuter une commande (ex: Administrateur).

B. Données Volontaires (Contenu)

Contenu des Commandes : Le texte, les arguments ou les pièces jointes envoyés spécifiquement lors de l'exécution d'une commande (ex: /commande [texte]).

Paramètres de Configuration : Si vous êtes administrateur d'un serveur, nous stockons les préférences que vous définissez pour votre serveur (langue, préfixes, rôles autorisés, journaux de logs).

3. Finalité du Traitement
Les données collectées sont utilisées exclusivement pour les objectifs suivants :

Exécution du Service : Répondre à vos commandes et fournir les fonctionnalités demandées.

Persistance : Sauvegarder vos configurations pour qu'elles ne soient pas perdues lors d'un redémarrage des Services.

Sécurité et Maintenance : Analyser les erreurs techniques (logs de débogage) et prévenir les abus (système anti-spam).

Nous n'utilisons jamais vos données pour du profilage commercial, de la publicité ciblée ou de la revente à des tiers.

4. Stockage et Conservation des Données
Vos données sont hébergées sur des serveurs sécurisés.

Données temporaires : Les logs techniques et le contenu des messages traités sont généralement conservés pour une durée maximale de 30 jours avant d'être écrasés.

Données persistantes : Les configurations de serveur et les données liées au profil utilisateur (ex: niveaux, économie virtuelle) sont conservées tant que les Services sont utilisés par l'Utilisateur ou présents sur le serveur.

Si les Services sont retirés d'un serveur (Kick/Ban), les données de configuration associées peuvent être supprimées immédiatement ou conservées pendant une période de grâce (ex: 30 jours) pour permettre une restauration en cas de réinvitation.

5. Partage des Données
Vos données personnelles ne sont jamais partagées avec des tiers, sauf dans les cas suivants :

Obligation Légale : Pour se conformer à une procédure judiciaire valide.

Sécurité : Pour protéger les droits, la propriété ou la sécurité du Développeur, de ses utilisateurs ou du public.

Discord Inc. : En utilisant les Services sur Discord, les données transitent nécessairement par les serveurs de Discord Inc., dont la politique de confidentialité est distincte de la nôtre.

6. Droits de l'Utilisateur
Conformément aux lois applicables sur la protection des données, vous disposez des droits suivants concernant vos informations :

Droit d'accès : Demander une copie des données que nous détenons sur vous.

Droit de rectification : Corriger des données inexactes.

Droit à l'effacement (Droit à l'oubli) : Demander la suppression de toutes vos données de nos bases de données.

Pour exercer ces droits, veuillez nous contacter via notre support ou utiliser les commandes de suppression de données intégrées aux Services si elles sont disponibles.

7. Modifications de la Politique
Nous pouvons mettre à jour cette politique de confidentialité périodiquement. La version la plus récente sera toujours accessible via la commande d'information des Services ou sur notre page officielle. Votre utilisation continue des Services après ces changements constitue votre acceptation de la politique révisée.
